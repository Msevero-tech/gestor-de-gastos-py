# Gestor de Gastos en Python

Proyecto simple realizado en Python para organizar gastos y presupuestos.

## Funciones
- Registro de gastos
- Cálculo de total gastado
- Promedio de gastos
- Gasto más alto y más bajo
- Comparación con presupuesto
- Porcentaje del presupuesto utilizado

## Tecnologías utilizadas
- Python
